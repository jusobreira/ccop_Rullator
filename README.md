# 🏴‍☠️ [Nome do Seu Projeto] (ex: RulePose)

Um simulador de campo e sandbox focado em auxiliar juízes e jogadores de **One Piece TCG** a recriarem cenários complexos, testarem interações de cartas e resolverem situações hipotéticas de regras.

## 🎯 Objetivo

O cenário competitivo de OPTCG exige um entendimento profundo sobre o tempo de efeitos e interações de cartas. Este projeto visa oferecer uma plataforma onde é possível:
- Configurar o tabuleiro rapidamente escolhendo qualquer carta.
- Simular estados de jogo complexos.
- Validar resoluções de efeitos (Sandbox Mode).

## 🚀 Funcionalidades Atuais

- **Modo Sandbox:** Posicionamento livre de cartas nas áreas do tabuleiro (Life, Deck, Trash, Character, Leader, Stage).
- **Gerenciamento de DON!!:** Contadores interativos para simular custos e efeitos de "DON!! -X".
- *(Em breve)* Motor de regras para validação de jogadas ilegais.
- *(Em breve)* Banco de dados integrado com informações completas das cartas.

## 🛠️ Tecnologias Utilizadas

Este projeto foi construído com foco em performance e ferramentas modernas de front-end:

- **[React](https://reactjs.org/)** - Biblioteca principal para a interface.
- **[Vite](https://vitejs.dev/)** - Bundler ultrarrápido para o ambiente de desenvolvimento.
- **[Tailwind CSS v4](https://tailwindcss.com/)** - Estilização utilitária e moderna.
- **[shadcn/ui](https://ui.shadcn.com/)** - Componentes de interface acessíveis e customizáveis.
- **[Vercel](https://vercel.com/)** - Hospedagem e CI/CD.
